Opportunity cost

Expected investment return after investment taxes, before subtracting inflation. The starting example uses 8.5% p.a. This is a planning assumption, not guaranteed income. The effective return below adjusts for inflation using (1 + return) / (1 + inflation) − 1, with percentages expressed as fractions. A negative result means purchasing power falls. The separate inflation switches convert comparison results to today’s purchasing power.

Opportunity cost accounts for the investment return you give up by paying earlier. Paying in instalments leaves money available to invest for longer; VAT refunds also release cash.

With only “Show costs in today’s money” enabled, future repayments cost less in purchasing-power terms, but future resale proceeds are also worth less. A loan can improve relative to buying outright even if its own total cost rises. Turn opportunity cost off to see this inflation effect on its own.

With both switches enabled, the investment return already values the benefit of paying later. “Today’s money” then converts the end-of-term costs into today’s purchasing power. For equal terms, every option is divided by the same inflation factor, so rankings and percentage differences stay unchanged. Different terms have different conversion factors. Applying another inflation discount to the loan principal would count the timing benefit twice.

How the timing calculation works

For each payment or receipt: amount × [(1 + nominal after-tax annual return)months remaining / 12 − 1]. Receipts use negative amounts. Refunds after the comparison end are discounted back to that date. With today’s money on, each contribution is amount × [(1 + return)^((end month − payment month)/12) / (1 + inflation)^(end month/12) − 1 / (1 + inflation)^(payment month/12)].
